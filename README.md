# Notchverse Recorder

The screen recorder that Notchverse installs when you press record in the notch. Record your screen or a window, with mic, system audio and a camera bubble, then edit in the studio: auto-zoom, cursor effects, backgrounds, captions and export.

**Download:** see [Releases](../../releases). Apple Silicon Macs, macOS 14 or later.

Notchverse installs it for you, so you normally never download it by hand.

## Credit

Notchverse Recorder is a rebranded build of **[OpenScreen](https://github.com/siddharthvaddem/openscreen)** by Siddharth Vaddem, used under the MIT licence (see [LICENSE](LICENSE)). The changes are the name and branding, a toolbar that always accepts clicks, and a floating camera preview while recording.
